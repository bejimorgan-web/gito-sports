### ✅ Disk Pressure Protection (Lines 106-107)

**Implementation**:
```typescript
const minimumBackupHeadroomBytes = 16 * 1024 * 1024;  // 16 MB

function requiredBackupSpace(databasePath: string) {
  const databaseSize = fs.statSync(databasePath).size;
  return databaseSize * 2 + minimumBackupHeadroomBytes;  // 2x DB + 16 MB
}
```

**Usage** (from safeCreateBackupFile):
```typescript

  throw new Error("Insufficient disk space for backup");
}
```

**Protection**:
- ✓ Requires 2× production DB size + 16 MB

### ✅ Single-Flight Mutex (Lines 280-289)

**Implementation**:
```typescript
let backupInFlight = false;

async function safeCreateBackupFile(backupPath: string): Promise<void> {
  if (backupInFlight) {
    throw new Error("backup_already_in_progress");
  }
  backupInFlight = true;
  try {
    await createSchemaPreservingBackup(databasePath, backupPath);
  } finally {
    backupInFlight = false;
  }
}
```

**Protection**:
- ✓ Only one backup can run at a time
- ✓ Prevents multiple temp files
- ✓ Prevents partial backup interleaving
- ✓ Prevents database lock contention
